Local subtitle folder

FastStream checks this folder for matching SRT files whenever you open a video.

In SubtitleCat, set the download subfolder to SRT and turn off “Ask where to save each SRT”. Use the full path to that same folder below.

Persistent folder access — recommended for Brave

The local helper remembers your folder across browser restarts. It only reads matching SRT files and does not run a network server. No Brave flags are needed.

First-time helper installation (Linux)

From your FastStream checkout, run this command once, then click Save and connect. If the installer already configured your folder, you may leave the path empty.

Reload FastStream after updating it. Its native-messaging permission allows it to communicate with the installed helper.

Browser-only alternative

Brave may require you to restore this method’s folder access after browser restarts. The local helper above avoids that repeated step.

For this alternative, enable File System Access API at brave://flags/#file-system-access-api, then relaunch Brave.
